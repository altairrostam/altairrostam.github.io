## Context

A catalog with thousands of models and datasets has more than one search problem. Some users know exactly what they want. Others are exploring a task, modality, or capability.

## What Changed

The system became more useful when retrieval stopped treating all queries the same way. Exact terms, filters, and semantic intent each received a dedicated path through the ranking pipeline.

## System Implications

Hybrid retrieval adds operational complexity, but it also creates knobs for debugging. When search fails, the team can inspect which signal underperformed.

## Practical Takeaway

Do not flatten a technical catalog into embeddings too early. Preserve structure, then let semantic search complement it.
