## Context

Vector search makes demos feel magical because it handles vague intent well. In production catalogs, though, users do not only ask vague questions. They search for exact model families, dataset names, licenses, tasks, providers, and benchmark terms.

## What Changed

The system became more reliable once vectors stopped being the only source of truth. Keyword scoring handled exact text. Structured metadata handled filters and facets. Vector similarity handled semantic expansion.

## System Implications

Hybrid search asks more of the engineering team. Ranking logic needs observability, and each signal needs a clear reason to exist. The payoff is that failures become debuggable instead of mysterious.

## Practical Takeaway

Use vectors as one ranking signal, not as an excuse to flatten the rest of the domain model. The more technical the catalog, the more valuable structured metadata becomes.
