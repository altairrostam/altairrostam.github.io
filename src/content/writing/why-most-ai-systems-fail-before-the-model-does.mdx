## Context

It is easy to blame the model when an AI system disappoints. Often the model never had a fair chance because the system around it was vague.

## What Changed

Better outcomes came from improving context flow, retrieval quality, evaluation practices, and user-facing constraints before chasing another model upgrade.

## System Implications

Teams need to evaluate complete workflows. The question is not only whether a model can answer, but whether the product supplied the right context and handled the answer responsibly.

## Practical Takeaway

Before replacing the model, inspect the system. The failure is often hiding in the plumbing.
